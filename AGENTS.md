# Agent Instructions

When working on this project, ALWAYS consult the contents of the `meta/` directory for the complete technical specification and implementation guidelines first.

The spec defines:
- Core architecture and constraints
- File structure and artifact definitions
- Command workflows and preconditions
- Safety rules and recovery procedures

Always reference the spec when implementing features or answering questions about Shpeck's design.

Never start implementing or editing code unless explicitly given the go-ahead. 
When working with a defined multi-step implementation plan, never skip ahead to following steps until you have explicit permission.

If you are requested to make code changes, always consider if the spec needs updating alongside the code. The code and the spec MUST NOT diverge.
